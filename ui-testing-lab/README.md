# UI Testing Lab

A comprehensive Playwright UI automation practice playground with 30+ interactive test scenarios covering common web UI patterns.

## Sections

- **Forms & Inputs** — Login, checkboxes, dropdowns, inputs, file upload/download, forgot password, WYSIWYG editor
- **Dynamic Content** — Dynamic controls, loading, content, add/remove elements, disappearing/shifting content, infinite scroll
- **Interactions** — Alerts, key presses, hovers, drag & drop, slider, context menu, multiple windows
- **Tables & Data** — Sortable data tables, data tables
- **Advanced** — Notifications, status codes, shadow DOM, nested frames, floating menu, entry ad, exit intent, broken images, redirect, typos, challenging DOM

## Usage

Open `playwright-ui-testing-lab.html` in any browser. No server or build step required.

```bash
open playwright-ui-testing-lab.html
```
